# Referensi API

## Fungsi

### `convertQRIS(qris, options): string`

Konversi QRIS statis → dinamis. Mengubah point of initiation `11`→`12`, menyuntik Transaction Amount (tag 54) + biaya opsional, lalu menghitung ulang CRC16.

```ts
convertQRIS(qris, { amount: 75000 });
convertQRIS(qris, { amount: 75000, fee: { type: "fixed", value: 1000 } });
convertQRIS(qris, { amount: 75000, fee: { type: "percentage", value: 2 } });
```

`options`: `{ amount: number; fee?: { type: "fixed"|"percentage"; value: number } }`. Melempar jika `amount` bukan positif atau input malformed.

### `validateQRIS(qris): { valid: boolean, errors: string[] }`

Cek struktur + integritas CRC16. **Tidak pernah melempar.** Menolak: payload terlalu pendek, CRC hilang/malformed, tag 63 sebelum posisi akhir (CRC duplikat/awal), CRC mismatch.

```ts
const { valid, errors } = validateQRIS(qris);
```

### `parseQRIS(qris): QrisMeta`

Parse metadata manusia-bisa-baca. Melempar pada input malformed. Mengembalikan `method`, `currency`, `countryCode`, `merchantName`, `merchantCity`, `postalCode`, `amount?`, `provider?`, `issuerGui?`, `merchantAccountInfo?`, `additionalData?`.

```ts
const meta = parseQRIS(qris);
```

### `parseTLV(qris): TLV[]` · `buildTLV(elements): string` · `makeTLV(tag, value): TLV`

TLV (Tag-Length-Value) tingkat lanjut — parse / susun, mendukung nested (tag 26–51, 62).

### `crc16(str): string`

CRC-16/CCITT-FALSE (CRC standar QRIS/EMVCo). Nilai uji kanonik: `crc16("123456789") === "29B1"`.

### `providerFromGui(gui): string`

Nama provider ramah dari Globally Unique Identifier. GUI tak dikenal → kembalikan GUI mentah.

## Tipe

| Tipe | Bidang |
|---|---|
| `QrisMeta` | `method`, `currency`, `countryCode`, `merchantName`, `merchantCity`, `postalCode`, `amount?`, `provider?`, `issuerGui?`, `merchantAccountInfo?`, `additionalData?` |
| `MerchantAccountInfo` | `tag`, `gui`, `pan?`, `criteria?`, `fields` |
| `AdditionalData` | `billNumber?`, `mobileNumber?`, `storeLabel?`, `loyaltyNumber?`, `referenceLabel?`, `customerLabel?`, `terminalLabel?`, `purpose?`, `additionalConsumerDataRequest?`, `merchantTaxId?`, `merchantChannel?`, `paymentSystemSpecific?` |
| `ValidationResult` | `valid`, `errors` |
| `ConvertOptions` | `amount`, `fee?` |
| `TLV` | `tag`, `length`, `value`, `children?` |
| `QrisMethod` | `"static"` \| `"dynamic"` |

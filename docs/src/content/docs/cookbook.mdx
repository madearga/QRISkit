# Cookbook / Contoh

Pola umum di setiap runtime: parse → validate → convert (dengan biaya) → deteksi provider.

## Bun

```ts
import { convertQRIS, validateQRIS, parseQRIS } from "qriskit";

const dinamis = convertQRIS(qris, { amount: 50000, fee: { type: "fixed", value: 1000 } });
console.log(validateQRIS(dinamis).valid, parseQRIS(dinamis).provider);
```

## Node (ESM + CJS)

```ts
// ESM
import { convertQRIS } from "qriskit";
// CJS
const { convertQRIS } = require("qriskit");
```

## Browser

Lewat bundler (Vite/TanStack Start/etc.), `import { convertQRIS } from "qriskit"` — library murni TS, tanpa API Node, jalan di browser.

## Deno

```ts
import { convertQRIS, validateQRIS } from "qriskit";

const d = convertQRIS(qris, { amount: 75000 });
if (!validateQRIS(d).valid) throw new Error("invalid");
```

## Cloudflare Worker

```ts
import { convertQRIS, validateQRIS } from "qriskit";

export default {
  async fetch(req) {
    const qris = await req.text();
    const dinamis = convertQRIS(qris, { amount: 50000 });
    return new Response(dinamis, { status: validateQRIS(dinamis).valid ? 200 : 400 });
  },
};
```

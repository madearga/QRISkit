# qriskit

Toolkit **QRIS** (Quick Response Code Indonesian Standard) dalam TypeScript — **nol dependensi runtime**, **runtime-agnostik** (Bun, Node, browser, Deno, edge), tree-shakeable ESM+CJS, tipe ketat.

Konversi QRIS **statis → dinamis**, parse metadata lengkap (termasuk deteksi provider), dan validasi struktur + CRC16.

## Mulai

```bash
bun add qriskit
```

```ts
import { convertQRIS, validateQRIS, parseQRIS } from "qriskit";

const dinamis = convertQRIS(qrisStatis, { amount: 75000 });
const { valid } = validateQRIS(dinamis);
const meta = parseQRIS(dinamis); // { provider: "DANA", method: "dynamic", ... }
```

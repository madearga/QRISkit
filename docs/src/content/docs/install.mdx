# Instalasi & Penggunaan

## Instal

```bash
bun add qriskit
```

atau

```bash
npm install qriskit
```

Nol dependensi runtime. Berjalan di Bun, Node (≥18), browser, Deno, dan edge runtime.

## Quickstart

```ts
import { convertQRIS, validateQRIS, parseQRIS } from "qriskit";

const qrisStatis = "000201010211...6304XXXX";

// Konversi statis → dinamis (injek nominal + opsional biaya)
const dinamis = convertQRIS(qrisStatis, { amount: 75000 });
const denganBiaya = convertQRIS(qrisStatis, {
  amount: 75000,
  fee: { type: "fixed", value: 1000 }, // atau { type: "percentage", value: 2 }
});

// Validasi struktur + CRC16 (tidak pernah throw)
const { valid, errors } = validateQRIS(dinamis);

// Metadata lengkap — termasuk deteksi provider
const meta = parseQRIS(dinamis);
console.log(meta.provider);      // "DANA" | "ShopeePay" | "Bank Mandiri" | ...
console.log(meta.method);        // "dynamic"
console.log(meta.merchantName);  // ...
```

## Error handling

- `convertQRIS` dan `parseQRIS` **melempar** pada input malformed (seperti `JSON.parse`).
- `validateQRIS` **tidak pernah melempar** — selalu mengembalikan `{ valid, errors }`.

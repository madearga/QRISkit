# API Reference

## Functions

### `convertQRIS(qris, options): string`

Convert static QRIS → dynamic. Flips point of initiation `11`→`12`, injects Transaction Amount (tag 54) + optional fee, then recomputes CRC16.

```ts
convertQRIS(qris, { amount: 75000 });
convertQRIS(qris, { amount: 75000, fee: { type: "fixed", value: 1000 } });
convertQRIS(qris, { amount: 75000, fee: { type: "percentage", value: 2 } });
```

`options`: `{ amount: number; fee?: { type: "fixed"|"percentage"; value: number } }`. Throws if `amount` is non-positive or input is malformed.

### `validateQRIS(qris): { valid: boolean, errors: string[] }`

Checks structure + CRC16 integrity. **Never throws.** Rejects: too-short payload, missing/malformed CRC, a tag-63 before the final position (duplicate/early CRC), CRC mismatch.

```ts
const { valid, errors } = validateQRIS(qris);
```

### `parseQRIS(qris): QrisMeta`

Parses human-readable metadata. Throws on malformed input. Returns `method`, `currency`, `countryCode`, `merchantName`, `merchantCity`, `postalCode`, `amount?`, `provider?`, `issuerGui?`, `merchantAccountInfo?`, `additionalData?`.

```ts
const meta = parseQRIS(qris);
```

### `parseTLV(qris): TLV[]` · `buildTLV(elements): string` · `makeTLV(tag, value): TLV`

Low-level TLV (Tag-Length-Value) parse / build, with nested-children support (tags 26–51, 62).

### `crc16(str): string`

CRC-16/CCITT-FALSE (the QRIS/EMVCo CRC). Canonical check value: `crc16("123456789") === "29B1"`.

### `providerFromGui(gui): string`

Friendly provider name from a Globally Unique Identifier. Unknown GUI → returns the raw GUI.

# qriskit

A **QRIS** (Quick Response Code Indonesian Standard) toolkit in TypeScript — **zero runtime dependencies**, **runtime-agnostic** (Bun, Node, browser, Deno, edge), tree-shakeable ESM+CJS, strict types.

Convert static **QRIS → dynamic**, parse full metadata (including provider detection), and validate structure + CRC16.

## Install

```bash
bun add qriskit
```

```ts
import { convertQRIS, validateQRIS, parseQRIS } from "qriskit";

const dynamic = convertQRIS(staticQris, { amount: 75000 });
const { valid } = validateQRIS(dynamic);
const meta = parseQRIS(dynamic); // { provider: "DANA", method: "dynamic", ... }
```

# Comparison

Compiled from public research (npm + GitHub), as of 2026-08.

| | **qriskit** | `@prasetya/qris` | `@shamah/dynamic-qris` | `@fhylabs/qris-dynamic` | `qris-dinamis` (razisek) |
|---|:---:|:---:|:---:|:---:|:---:|
| Zero runtime deps | ✅ | ✅ | ✅ | ❌ | ❌ |
| Runtime-agnostic (browser/edge/Deno) | ✅ | ❌ | ❌ | ❌ | ❌ |
| Tree-shakeable ESM + CJS | ✅ | ✅ | ✅ | ❌ | ❌ |
| Strict TypeScript + types | ✅ | ✅ | ✅ | ✅ | ❌ |
| Validate + CRC check | ✅ | ✅ | ✅ | ❌ | ❌ |
| Actively maintained (2026) | ✅ | ✅ | ✅ | ⚠️ | ❌ |

> This is a quick snapshot, not a judgment — other packages have strengths qriskit lacks (e.g. `@fhylabs` has QR image generation). Open an [Issue](https://github.com/madearga/QRISkit/issues) to update stale data.

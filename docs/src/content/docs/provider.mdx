# Deteksi Provider

`parseQRIS` membaca **Globally Unique Identifier** (sub-tag 00) dari tag merchant-account-info (**26** retail, **40**, atau **51** lintas-batas) dan memetakannya ke nama provider yang ramah.

```ts
const meta = parseQRIS(qris);
meta.provider;   // "ShopeePay" | "DANA" | "Bank Mandiri" | ...
meta.issuerGui;  // "ID.CO.SHOPEE.WWW"
meta.merchantAccountInfo; // { tag: "40", gui, pan?, criteria?, fields }
```

## Provider yang dikenali

| GUI | Provider |
|---|---|
| `ID.CO.SHOPEE.WWW` | ShopeePay |
| `COM.GO-JEK.WWW` / `ID.GO-JEK.WWW` | GoPay |
| `ID.DANA.WWW` | DANA |
| `ID.OVO.WWW` | OVO |
| `ID.CO.BANKMANDIRI.WWW` | Bank Mandiri |
| `ID.CO.BCA.WWW` | BCA |
| `ID.CO.BRI.WWW` | BRI |
| `ID.CO.BNI.WWW` | BNI |
| `ID.LINKAJA.WWW` | LinkAja |
| `ID.CO.XENDIT.WWW` | Xendit |
| `ID.CO.QRIS.WWW` | QRIS (generic) |

## GUI tak dikenal

Jika GUI tidak ada di tabel, `provider` mengembalikan **GUI mentah** — tidak pernah throw, dan library tetap bekerja.

> Peta provider adalah data yang dikelola in-repo, **bukan verifikasi registry resmi Bank Indonesia** — bukan klaim otoritatif. `providerFromGui(gui)` mengekspos pencarian yang sama untuk penggunaan langsung.

## Terverifikasi di data issuer nyata

Deteksi telah diuji terhadap QRIS merchant sungguhan: **ShopeePay** (tag 40), **Bank Mandiri** (tag 26), dan **DANA** (tag 26).
